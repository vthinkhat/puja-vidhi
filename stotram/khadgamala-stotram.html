ಖಡ್ಗಮಾಲಾ ಸ್ತೋತ್ರಂ (Khadgamala Stotram)

Rules:

ಓಂ ಐಂ ಹ್ರೀಂ ಶ್ರೀಂ ಐಂ ಕ್ಲೀಂ ಸೌಃ

ಓಂ ನಮಃ ತ್ರಿಪುರಸುಂದರಿ Tripura is within us and also the tipura asuras. Mother remove the impurities from these 3 puras and fills them with living energy.

Aavaraname / Chakram 1: Anganyasa devatas (6)

ಹೃದಯದೇವಿ, ಶಿರೋದೇವಿ, ಶಿಖಾದೇವಿ, ಕವಚದೇವಿ, ನೇತ್ರದೇವಿ, ಅಸ್ತ್ರದೇವಿ Enable reading this stotram without need for Anganyasam.

Aavaraname / Chakram 1: Thithi-vidhya devatas (15) + Shodasi/Ammavaaru (1)

ಕಾಮೇಶ್ವರಿ, ಭಾಗಮಾಲಿನಿ, ನಿತ್ಯಕ್ಲಿನ್ನೆ, ಭೇರುಂಡೆ,
ವಹ್ನಿವಾಸಿನಿ, ಮಹಾವಜ್ರೇಶ್ವರಿ, ಶಿವದೂತಿ, ತ್ವರಿತೇ,
ಕುಲಸುಂದರಿ, ನಿತ್ಯೆ, ನೀಲಪತಾಕೆ, ವಿಜಯೆ,
ಸರ್ವಮಂಗಲೆ, ಜ್ವಾಲಾಮಾಲಿನಿ, ವಿಚಿತ್ರೆ, ಶ್ರೀವಿದ್ಯೆ 15 Thithi-vidhya devatas each of the 15 thithis. 16th is the actual Ammavaaru, called Shodasi.

Aavaraname / Chakram 1: Guru Parampara

ದಕ್ಷಿಣಾಮೂರ್ತಿಮಯಿ, ನಾರಾಯಣಮಯಿ, ಬ್ರಹ್ಮಮಯಿ, ಸನಕಮಯಿ,
ಸನಂದನಮಯಿ, ಸನಾತನಮಯಿ, ಸನತ್ಕುಮಾರಮಯಿ, ಸನತ್ಸುಜಾತಮಯಿ,
ವಶಿಷ್ಠಮಯಿ, ಶಕ್ತಿಮಯಿ, ಪರಾಶರಮಯಿ, ಕೃಷ್ಣದ್ವೈಪಾಯನಮಯಿ,
ಪೈಲಮಯಿ, ವೈಶಂಪಾಯನಮಯಿ, ಜೈಮಿನಿಮಯಿ, ಸುಮಂತುಮಯಿ,
ಶ್ರೀಶುಕಮಯಿ, ಗೌಡಪಾದಮಯಿ, ಗೋವಿಂದಮಯಿ, ಶ್ರೀವಿದ್ಯಾಶಂಕರಮಯಿ,
ಪದ್ಮಪಾದಮಯಿ, ಹಸ್ತಾಮಲಕಮಯಿ, ತ್ರೋಟಕಮಯಿ, ಸುರೇಶ್ವರಮಯಿ,
ವಿದ್ಯಾರಣ್ಯಮಯಿ, ಪರಮೇಷ್ಠಿಗುರು ಶ್ರೀ _ _ _ _ ಮಯಿ
ಪರಮಗುರು ಶ್ರೀ _ _ _ _ ಮಯಿ, ಸ್ವಗುರು ಶ್ರೀ _ _ _ _ ಮಯಿ

Consider Kalyaanananda Bharathi Swamy -- revised this Khadgamaala stotram.
When entering a chakra, first recite its name and do namaskara to Yogini Ganam, and when exiting, do namaskara to Chakreshwari before proceeding to the next chakra.

Aavaraname / Chakram 1: Trilokya Mohana Chakram (3 squares)

Aavaraname / Chakram 1: Yogini
ತ್ರೈಲೋಕ್ಯಮೋಹನ ಚಕ್ರಸ್ವಾಮಿನಿ, ಪ್ರಕಟಯೋಗಿನಿ →
Aavaraname / Chakram 1: Bhoopura 1: Siddhi devatas (10)
→ ಅಣಿಮಾ ಸಿದ್ಧೆ, ಲಘಿಮಾ ಸಿದ್ಧೆ, ಮಹಿಮಾ ಸಿದ್ಧ, ಈಶಿತ್ವಸಿದ್ಧೆ, ವಶಿತ್ವಸಿದ್ಧೆ,
ಪ್ರಾಕಾಮ್ಯಸಿದ್ಧೆ, ಭುಕ್ತಿಸಿದ್ಧೆ, ಇಚ್ಛಾಸಿದ್ಧೆ, ಪ್ರಾಪ್ತಿಸಿದ್ಧೆ, ಸರ್ವಕಾಮಸಿದ್ಧೆ
Aavaraname / Chakram 1: Bhoopura 2: Ashta Maatrukas (8)
→ ಬ್ರಾಹ್ಮಿ, ಮಾಹೇಶ್ವರಿ, ಕೌಮಾರಿ, ವೈಷ್ಣವಿ, ವಾರಾಹಿ, ಮಾಹೇಂದ್ರಿ, ಚಾಮುಂಡೆ, ಮಹಾಲಕ್ಷ್ಮಿ
Aavaraname / Chakram 1: Bhoopura 3: Mudra Devatas (10)
→ ಸರ್ವಸಂಕ್ಷೋಭಿಣಿ, ಸರ್ವವಿದ್ರಾವಿಣಿ, ಸರ್ವಾಕರ್ಷಿಣಿ, ಸರ್ವವಶಂಕರಿ, ಸರ್ವೋನ್ಮಾದಿನಿ,
ಸರ್ವಮಹಾಂಕುಶೆ, ಸರ್ವಖೇಚರಿ, ಸರ್ವಬೀಜೆ, ಸರ್ವಯೋನೆ, ಸರ್ವತ್ರಿಖಂಡೆ
Aavaraname / Chakram 1: Chakreshwari
← ತ್ರಿಪುರೇ

Aavaraname / Chakram 2: Sarvaashaa Paripurna Chakram (16 petal)

16 petals:

Aavaraname / Chakram 2: Yogini
ಸರ್ವಾಶಾಪರಿಪೂರಕ ಚಕ್ರಸ್ವಾಮಿನಿ, ಗುಪ್ತಯೋಗಿನಿ →
Aavaraname / Chakram 2: Gupta Yoginis
ಕಾಮಾಕರ್ಷಿಣಿ, ಬುದ್ಧ್ಯಾಕರ್ಷಿಣಿ, ಅಹಂಕಾರಾಕರ್ಷಿಣಿ, ಶಬ್ದಾಕರ್ಷಿಣಿ, ಸ್ಪರ್ಶಾಕರ್ಷಿಣಿ,
ರೂಪಾಕರ್ಷಿಣಿ, ರಸಾಕರ್ಷಿಣಿ, ಗಂಧಾಕರ್ಷಿಣಿ, ಚಿತ್ತಾಕರ್ಷಿಣಿ, ಧೈರ್ಯಾಕರ್ಷಿಣಿ,
ಸ್ಮೃತ್ಯಾಕರ್ಷಿಣಿ, ನಾಮಾಕರ್ಷಿಣಿ, ಬೀಜಾಕರ್ಷಿಣಿ, ಆತ್ಮಾಕರ್ಷಿಣಿ, ಅಮೃತಾಕರ್ಷಿಣಿ,
ಶರೀರಾಕರ್ಷಿಣಿ
Aavaraname / Chakram 2: Chakreshwari
← ತ್ರಿಪುರೇಶಿ

Aavaraname / Chakram 3: Sarva Sankshobhana Chakram (8 petals)

Aavaraname / Chakram 3: Yogini
ಸರ್ವಸಂಕ್ಷೋಭಣ ಚಕ್ರಸ್ವಾಮಿನಿ, ಗುಪ್ತತಾರ ಯೋಗಿನಿ
Aavaraname / Chakram 3:
→ ಅನಂಗಕುಸುಮೇ, ಅನಂಗಮೇಖಲೇ, ಅನಂಗಮದನೇ, ಅನಂಗಮದನಾತುರೇ,
ಅನಂಗರೇಖೇ, ಅನಂಗವೇಗಿನಿ, ಅನಂಗಾಂಕುಶೇ, ಅನಂಗಮಾಲಿನಿ
Aavaraname / Chakram 3: Chakreshwari
← ತ್ರಿಪುರಸುಂದರಿ

Aavaraname / Chakram 4: Sarva Soubhagya Dayaka Chakram (14 triangles)

Aavaraname / Chakram 4: Yogini
ಸರ್ವಸೌಭಾಗ್ಯದಾಯಕ ಚಕ್ರಸ್ವಾಮಿನಿ, ಸಂಪ್ರದಾಯ ಯೋಗಿನಿ
Aavaraname / Chakram 4:
→ ಸರ್ವಸಂಕ್ಷೋಭಿಣಿ, ಸರ್ವವಿದ್ರಾವಿಣಿ, ಸರ್ವಾ ಕರ್ಶಿಣಿ, ಸರ್ವಾ ಹ್ಲಾದಿನಿ,
ಸರ್ವ ಸಮ್ಮೋಹಿನಿ, ಸರ್ವ ಸ್ಥಂಭಿನಿ, ಸರ್ವ ಜೃಂಭಿಣಿ, ಸರ್ವ ವಶಂಕರಿ,
ಸರ್ವರಂಜನಿ, ಸರ್ವೋನ್ಮಾದಿನಿ, ಸರ್ವಾರ್ಥ ಸಾಧಿನಿ, ಸರ್ವಸಂಪತ್ತಿಪೂರಿಣಿ,
ಸರ್ವ ಮಂತ್ರಮಯೀ, ಸರ್ವ ದ್ವಂದ್ವ ಕ್ಷಯಂಕರಿ
Aavaraname / Chakram 4: Chakreshwari
← ತ್ರಿಪುರವಾಸಿನಿ

Aavaraname / Chakram 5: Sarvaartha Saadhaka Chakram (10 triangles)

Aavaraname / Chakram 5: Yogini
ಸರ್ವಾರ್ಥಸಾಧಕ ಚಕ್ರಸ್ವಾಮಿನಿ, ಕುಲ ಯೋಗಿನಿ
Aavaraname / Chakram 5:
→ ಸರ್ವಸಿದ್ಧಿಪ್ರದೇ, ಸರ್ವ ಸಂಪತ್ಪ್ರದೇ, ಸರ್ವ ಪ್ರಿಯಂಕರಿ, ಸರ್ವ ಮಂಗಳ ಕಾರಿಣಿ,
ಸರ್ವ ಕಾಮಪ್ರದೇ, ಸರ್ವ ದುಃಖ ವಿಮೋಚನಿ, ಸರ್ವ ಮೃತ್ಯು ಪ್ರಸಮನಿ,
ಸರ್ವ ವಿಘ್ನ ನಿವಾರಿಣಿ, ಸರ್ವಾಂಗ ಸುಂದರಿ, ಸರ್ವ ಸೌಭಾಗ್ಯ ದಾಯಿನಿ
Aavaraname / Chakram 5: Chakreshwari
← ತ್ರಿಪುರಾ ಶ್ರೀಃ

Aavaraname / Chakram 6: Sarva Rakshakara Chakram (10 triangles)

Aavaraname / Chakram 6: Yogini
ಸರ್ವರಕ್ಷಾಕರ ಚಕ್ರಸ್ವಾಮಿನಿ, ನಿಗರ್ಭಯೋಗಿನಿ
Aavaraname / Chakram 6:
→ ಸರ್ವಜ್ಞೇ, ಸರ್ವಶಕ್ತೇ, ಸರ್ವೈಶ್ವರ್ಯ ಪ್ರದಾಯಿನಿ, ಸರ್ವಜ್ಞಾನಮಯೀ,
ಸರ್ವವ್ಯಾಧಿ ವಿನಾಶಿನಿ, ಸರ್ವಾಧಾರ ಸ್ವರೂಪೇ, ಸರ್ವಪಾಪಹರೇ,
ಸರ್ವಾನಂದಮಯೀ, ಸರ್ವರಕ್ಷಾಸ್ವರೂಪಿಣಿ, ಸರ್ವ ಈಪ್ಸಿತಾರ್ಥಪ್ರದೇ
Aavaraname / Chakram 6: Chakreshwari
← ತ್ರಿಪುರಮಾಲಿನಿ

Aavaraname / Chakram 7: Sarva Rogha Hara Chakram (8 triangles)

Aavaraname / Chakram 7: Yogini
ಸರ್ವ ರೋಗ ಹರ ಚಕ್ರಸ್ವಾಮಿನಿ, ರಹಸ್ಯ ಯೋಗಿನಿ
Aavaraname / Chakram 7:
→ ವಶಿನಿ, ಕಾಮೇಶ್ವರಿ, ಮೋದಿನಿ, ವಿಮಲೆ, ಅರುಣೇ, ಜಯಿನಿ, ಸರ್ವೇಶ್ವರಿ, ಕೌಳಿನಿ
Aavaraname / Chakram 7: Chakreshwari
← ತ್ರಿಪುರಾ ಸಿದ್ಧೇ

Aavaraname / Chakram 8: Sarva Siddhi Pradha Chakram (1 triangle + 1 square)

Aavaraname / Chakram 8: Yogini
ಸರ್ವ ಸಿದ್ಧಿ ಪ್ರದ ಚಕ್ರಸ್ವಾಮಿನಿ, ಅತಿರಹಸ್ಯ ಯೋಗಿನಿ
Aavaraname / Chakram 8:
→ ಬಾಣಿನಿ, ಚಾಪಿನಿ, ಪಾಶಿನಿ, ಅಂಕುಶಿನಿ, ಮಹಾಕಾಮೇಶ್ವರಿ, ಮಹಾವಜ್ರೇಶ್ವರಿ,
ಮಹಾಭಾಗಮಾಲಿನಿ
Aavaraname / Chakram 8: Chakreshwari
← ತ್ರಿಪುರಾಂಬಿಕೆ

Aavaraname / Chakram 9: Yogini
